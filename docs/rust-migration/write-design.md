# 阶段 3 写入、审核与文件引用

温晓的执行设计，2026-09-14。沿用阶段 0 的路由、字段和响应契约；下列并发约束作为苏瑶实现与测试的验收条件。

## 点位与收藏

- 创建点位保持 HTTP 200、默认公开和 PENDING 审核状态。用户公共 ID 是归属依据，用户名仅作快照。客户端幂等键按既有规则 trim、空白转 null、最多 64；`(user_public_id, client_request_id)` 唯一约束处理并发重放，首次与重复请求返回同一个点位。不能因捕获任意数据库错误而假称命中幂等。
- 创建、编辑的坐标与字段长度在入库前校验。PATCH 的缺失/null/空串按既有 DTO 语义处理；不新增客户端必填的版本字段或擅自把普通用户编辑改成直接保存。
- 普通用户编辑创建 PENDING 编辑提案，记录当前点位版本。即使原文与翻译同时发生编辑，也通过同一个 marker.version 仲裁。
- 收藏使用已有唯一约束，重复 POST 和 DELETE 均成功。创建收藏时在事务中对点位取得 `FOR KEY SHARE` 或等价保护，验证可见性后插入，避免与点位删除交错产生新孤立收藏。
- 删除在一个事务中锁定点位、验证属主/管理员、删除收藏和译文、删除点位。已存在的审核提案按原有历史记录规则保留；不能将提案关联缺失误判为可访问图片。
- 所有读接口继续在读时计算开放状态，不把计算结果写回数据库。

## 本地化修改

更新原文时修改 sourceLanguage 对应文本并推进 marker.version；其它语言作为 `origin=MANUAL` 的译文保存，其 sourceHash 根据更新后的原文计算。译文写入和点位版本更新必须使用同一 PG 事务与连接。

首次提交某语言译文而没有有效旧译文时，需要同时提供标题和描述，描述可以为空串。只有非文本字段变化时，不凭空将原文语言切换为请求语言。已有有效译文允许按原有规则补齐未提供的文本字段。

源文本变化使旧译文因 hash 不同而失效，不删除或假装它仍有效。人工译文的 origin 标记继续保留，避免后续批处理误覆盖。

## 审核的一次性处理

编辑提案审核在同一事务内锁提案、检查 PENDING、锁点位、核对 baseMarkerVersion、更新点位与译文、写提案审核人和时间，然后提交。版本缺失或过期返回 409，提案仍待审；重复处理返回 400。同一提案的两名管理员只能有一人成功。

图片提案虽然旧表没有 version，也必须通过行锁或条件状态更新保证一次性处理。关联点位图片 URL 的更新、marker.version 推进和提案状态更新在同一事务中提交，失败时全部回滚。不同图片提案可以依次处理，不伪造表中不存在的图片提案基准版本。

点位直接审核和管理员直接编辑保持原有接口；数据库版本冲突返回既有 409 形状。锁顺序保持一致，数据库错误不泄露 SQL 参数、用户资料或密码。

## 缓存与媒体

PG 提交成功后再使点位缓存 generation 递增。缓存首次失效也必须改变代次；代次不按时间重置。Redis 失败记录受控信息，不能把已经提交的写入报告为数据库回滚。缓存 TTL 作为故障恢复的补充；点位当前可见性仍由 PG 决定。

图片通过已验收的 ImageStore 校验和重编码，落盘成功后才能写入头像/图片提案引用。请求总量 8 MiB、单文件 5 MiB；multipart 显式覆盖 Axum 默认 2 MiB，并在分块读取中检查单文件大小。CPU 许可必须随实际阻塞任务结束释放。

数据库写入失败时可以清理本次新建且确认无引用的文件；结果不确定或任务被取消时保留可清理孤立文件，不删除可能已经提交引用的文件。历史文件在确认没有任何用户、点位或提案引用前不得删除。本轮不添加扫描整个上传目录的自动删除任务。

受控媒体读取在授权后流式发送。头像与点位图片沿用既有 URL；点位图片授权包括直接引用和历史提案引用，后者必须有仍存在的关联点位，并按原有管理员/属主/提案作者规则判断。提案状态本身不是可读条件。非法路径或不可见资源保持 404。

清理失效点位图片链接时只清理确实缺失或非普通文件的受控路径，保留仍存在的文件；条件更新同时匹配原 URL/版本，避免把并发换上的新图片清掉。磁盘权限或暂时 I/O 故障不能等同于文件缺失。

## 阶段验收

真实 PG/Redis/临时文件覆盖：幂等创建与收藏、收藏和删除竞争、属主及匿名可见性、两个管理员同时审核、两个同基准版本提案竞争、过期和缺版本提案、原文与译文并发、强制译文写入失败后的整体回滚、图片审核失败回滚、图片越权及路径穿越、5 MiB/8 MiB 上传边界、提交后缓存失效故障。

每个独立改动通过审查与针对性验证后提交；所有剩余现有路由接通且阶段门禁通过，才把阶段 3 标为完成并推送。生产切换、正式数据库接管及同负载性能测量仍属于阶段 4。
