# I2 — 四个画板的界面还原

2026-09-16，分支 `feat/ios-native`。温晓完成实现；辅助代理仅作设计规格核对和只读代码审阅。

## 交付与画稿对应

| 画板 | 实现 |
| --- | --- |
| 收起 `10:970` | 25pt 侧边距、66pt 基准高度、淡紫色材质、38pt 搜索/头像、18pt 头像字、右侧两组工具 |
| Nearby `45:169` | 10pt 侧边距、三类双列卡片、蓝色渐变厕所徽章、工具跟随面板；合并读取同级标题/卡片 |
| 完整 `45:248` | 三行收藏整卡、标题右侧箭头、四张独立设置卡与6pt间距；匿名不显示收藏整组 |
| 详情 `65:1989` | 标题、距离/时间、描述、原图、编辑、分享、导航、收藏、地图 pin；包含同级 Navigate 按钮 |

原始图标和照片来自 Figma MCP，没有重画或替换素材。搜索、标题、正文和辅助文字使用对应的系统 SF 字体；面板与按钮使用原生材质。尺寸、来源和缺稿边界见 [设计映射](design-mapping.md) 与 [素材清单](figma-assets.md)。

详情支持原档、全展开和收起；收藏行可以进入详情，雷达回到 Nearby。地图实例保持不变。大屏详情高度随照片宽高比增长，辅助字号下操作改为纵排，内容可滚动。

## 预览与真实业务的边界

- 默认启动匿名，收藏区及其占位都隐藏。预览启动参数和固定数据全部位于 `#if DEBUG`，不会构成真实登录态；Release 忽略预览参数。
- 五个 Xcode 预览：收起、Nearby、完整收藏态、完整匿名态、详情。运行参数说明见 [README](../README.md)。
- 画稿里的标题、照片、距离、时间以及 New Jersey 坐标是设计 fixture，不是经过核验的真实点位。
- 未接入的操作显示原生“暂不可用”提示，不进行真实分享、外部导航、投稿或收藏写入。真实功能按 I3–I6 实现；没有新增主导航或调试菜单。

## 验证记录

Xcode 26.6 / Swift 6.3.3，iOS 26.5 Simulator；iPhone 17（402×874pt）及 iPhone 17 Pro Max（440×956pt）。

- Figma MCP 读取四画板、同级节点、原素材与照片 fill 参数；Computer Use 查看模拟器实际渲染，XCTest 完成可靠的原生触摸与滚动操作。
- 12 项 Swift Testing 测试通过，涵盖配置、面板档位与边界、详情收起目的地，以及地图坐标/朝向保持。
- 两种尺寸的界面流程通过：收藏进入详情、展开与收起、未实现动作反馈、匿名收藏隐藏；原有地图拖动、键盘避让与保留搜索输入通过。
- 辅助字号单独检查详情长标题、滚动与操作可达性；头像首字母限制在圆形范围内。
- Debug/Release 构建、Swift 格式检查、工程和配置 plist 检查通过。

自动化会等待面板到达顶部后再点击，避免在 spring 动画过程中点击旧坐标。视觉以原稿布局与层级为依据；动态地图瓦片、系统状态栏、原生材质随背景的变化不作为逐像素一致项。真机、完整 VoiceOver/深色模式以及真实数据体验仍按后续阶段完成。
