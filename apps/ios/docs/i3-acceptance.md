# I3 — 地图与真实点位

2026-09-16，分支 `feat/ios-native`。温晓亲自实现；辅助代理只读核对 Rust 契约、运行环境和竞态边界。

## 已交付

- 保持单一 MapKit 实例，按当前范围读取 Rust 公共点位；跨日期线拆成两个范围并按 Int64 ID 去重。
- 搜索 300ms 防抖、视口 250ms 防抖，取消与请求代次同时校验。搜索、附近和详情各自管理状态。
- 三类卡片与雷达共用 Nearby，雷达默认无障碍厕所、范围 1km。进入时捕获中心，拖图不悄悄移动查询中心。首次地图回调尚未到达时，也保留附近查询意图。
- Core Location 仅由定位/附近入口触发 When In Use；允许后显示当前位置，拒绝或失败时以明确标注的地图中心查询。迟到的定位不能覆盖后来选中的点位或搜索。
- 地图 pin 与点位行都打开真实详情；缺少描述/照片时不注入画稿示例数据。图片使用公共无 Cookie 请求，失败保留文字详情。
- 详情 404 移除旧 pin，并重新读取剩余公共结果；列表支持加载、空结果、请求失败和重试。保留 HTTP 错误的 X-Request-ID 供诊断，不把服务器原始错误正文放入页面。
- 分享使用系统 UIActivityViewController，分享公开的 Apple Maps 目的地链接；导航使用 MKMapItem 打开 Apple 地图步行路线，不在分享中包含用户起点。
- 默认匿名，Bookmarks 继续隐藏；所有图稿 fixtures 仅在显式 Debug 预览中使用，预览不读 API、不执行真实分享/导航。Release 忽略预览与测试相机参数。
