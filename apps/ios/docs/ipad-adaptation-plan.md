# iPad 原生适配方案与验收计划

日期：2026-09-21。分支：`feat/ios-ipad`，基于 `feat/ios-native`。

## 目标

将现有 iPhone 应用扩展为同一 Bundle ID（`com.lycoris.maps`）的 iPhone / iPad 通用应用。继续使用 SwiftUI、MapKit 和系统 Liquid Glass，最低 iOS / iPadOS 26。宽屏的信息结构与操作方式参考现有 Web，具体控件、弹窗、键盘操作及无障碍采用原生实现。

当前应用只声明 iPhone 和竖屏；本轮补齐 iPad 设备声明、方向、自适应地图布局与验证。沿用现有 Rust API、账号、收藏、点位元数据、定位、语音及贡献上传逻辑。

## 布局与交互

| 可用窗口 | 布局 |
| --- | --- |
| 窄窗口 / iPhone | 保留地图及底部三级菜单；搜索、详情与拖动操作延续现有行为。 |
| 中等 iPad 窗口 | 紧凑原生导航栏、可关闭的内容栏、地图；避免多栏挤压地图。 |
| 足够宽的 iPad 窗口 | 带文字的原生导航栏、可关闭的内容栏、地图。 |

布局以窗口实际宽高计算，不以机型或横竖屏名称判断。初始分界采用 760pt 宽且至少 440pt 高进入侧栏布局，1180pt 起显示完整导航文字；根据模拟器验收调整。辅助内容栏约 340–380pt；文字使用系统字体并适应 Dynamic Type。

- 主导航包括搜索、登录后可见的收藏、贡献、设置、账号。
- 搜索及附近结果复用现有组件和请求状态；选择结果或地图点位，在内容栏打开详情并与地图联动。
- 关闭按钮关闭第二内容栏，保留主导航和地图；重新打开搜索保留查询内容。
- 收藏列表在内容栏呈现；未登录时隐藏收藏入口。账号变化时清理失效的私有内容。
- 登录、资料、设置、编辑、贡献及照片选择仍使用原生 sheet / Form / List；地图图层保留探索、卫星。
- 贡献仍默认当前位置，沿用“标注地图上其他位置”的显式选择流程。选点时让出地图，确认后回到同一草稿。
- 宽窄切换不清空搜索、点位选择、账号、地图位置或草稿，不重复申请权限。

## 结构与实现约束

1. `MapScreen` 保持业务状态的唯一所有者。`PlaceStore`、`AccountStore`、`ContributionStore`、定位和语音对象不随布局切换重建。
2. 根视图保留同一个 `NativeMapView`。使用原生 SwiftUI 导航列表、按钮、`NavigationStack`、工具栏及 Liquid Glass 组成侧栏，避免在两个完整页面之间替换地图。
3. 抽取纯布局计算及侧栏组件；复用现有搜索栏、点位详情、结果、收藏列表。手机面板继续使用 `PanelLayout`。
4. 地图遮挡从底部扩展到四边；宽屏左侧栏参与 MapKit 的可用区域计算。保持现有坐标转换及镜头稳定逻辑，避免重复校准和额外定位请求。
5. 键盘避让按当前应用窗口处理；浮动键盘不应把整个内容栏推离屏幕。表单继续使用系统键盘行为。
6. 新控件有语义标签、44pt 点击区域、选中状态和明确关闭动作。支持 VoiceOver、较大文字、减少动态效果与降低透明度。
7. iPhone 保持既有竖屏声明，iPad 声明四个方向。应用及测试 target 均覆盖 iPhone / iPad。新构建号递增，正式版本号仍为 0.1.0。

## 实施顺序与提交

### P1：方案落盘

- 提交本方案，记录现状、交互映射、状态保护和验收范围。

### P2：通用应用与自适应界面

- 启用 iPad、方向和新构建号。
- 完成原生导航、内容栏、窄窗口回退及地图遮挡计算。
- 接入搜索、附近、详情、收藏、设置、账号和贡献现有流程。
- 分部分进行规范 commit，阶段完成后 push。

### P3：验证与交付

- 执行布局和地图边距相关单元测试，以及适配流程 UI 测试。
- 在 11 英寸 / 13 英寸 iPad 验证横竖屏、窗口缩放、键盘、较大文字和主要界面；回归 iPhone。
- 检查通用应用构建产物的设备声明、方向、生产 API 和出口合规键。
- 补充验收记录和截图，记录模拟器无法证明的真机能力。

## 验收清单

- [ ] iPhone 与 iPad 均可构建、安装，设备声明和 iPad 方向正确。
- [ ] 宽屏搜索、附近列表、点位详情可用；关闭内容栏后导航及地图仍可操作。
- [ ] 匿名用户没有收藏入口；登录后可在内容栏浏览收藏并打开详情。
- [ ] 旋转、缩放、打开及关闭侧栏保持搜索文本、选中点位和地图镜头；地图实例不重建。
- [ ] 定位点与普通点位显示正常；定位按钮和选中点位聚焦考虑左侧遮挡。
- [ ] 贡献、编辑、地图选点、取消及恢复草稿沿用正确状态。
- [ ] 登录、设置、分享、照片选择等弹窗在 iPad 上尺寸与锚点合理。
- [ ] 键盘、较大文字、VoiceOver 标签及关闭动作可用。
- [ ] 手机底部菜单、搜索、详情和右侧工具保持可用。

本轮在本机开发验证并推送代码；TestFlight 上传及服务器部署不属于本轮执行范围。
