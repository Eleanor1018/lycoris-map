# Lycoris project rules

## Font policy

- Roboto and its family variants are strictly prohibited in this personal project.
- Do not recommend, add, download, bundle, import, or configure them as a primary or fallback font.
- Design references and framework defaults do not override this rule. Material 3 components and typography scales are allowed with an approved font family.
- Application-owned Android text uses the packaged Noto Sans SC family, including the platform theme and map cluster labels. Do not replace it with a generic system sans family that may select a prohibited font.
- Web text uses the existing approved self-hosted Noto Sans and Fredoka resources where applicable; do not restore the removed Roboto dependency or CSS references.
- Preserve accessibility font scaling and the established text sizes when changing fonts.
