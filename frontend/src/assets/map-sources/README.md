# Map preview attribution

The picker uses 160×160 provider previews, with linked attribution. These images
illustrate map appearance; they are not map tiles or an offline map source.

- `osm.webp`: streets near People's Square, Shanghai. © OpenStreetMap contributors,
  [ODbL and attribution](https://www.openstreetmap.org/copyright).
- `tianditu.webp`: Shanghai city map from [Tianditu](https://map.tianditu.gov.cn/).
  Source credits: 自然资源部 & NavInfo, GS（2025）1508号.
- `tencent.png`: unmodified image from Tencent's [Static Map API v2](https://lbs.qq.com/service/staticV2/staticGuide/staticOverview),
  centered at GCJ-02 31.228457,121.478224, zoom 14. © Tencent.

The OSM and Tianditu previews are map screenshot crops. Tencent's generation key
is not stored with its image. No browser/account UI or user location is bundled.
