Mainland geographic coverage mask

Natural Earth 1:10m Admin 0 Countries, version 5.1.1, public domain.
https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-countries/
https://www.naturalearthdata.com/about/terms-of-use/
Source archive: https://naturalearth.s3.amazonaws.com/10m_cultural/ne_10m_admin_0_countries.zip
Extracted ADM0_A3=CHN, excluding the separate HKG, MAC and TWN records.
Original WGS84 coordinate precision retained; exterior rings oriented counterclockwise.
70 polygons, 14,118 vertices. This is a cartographic coverage approximation.

Calibration reference: OpenStreetMap way 40778038, version 45, building vertex mean.
https://api.openstreetmap.org/api/0.6/way/40778038/full.json
