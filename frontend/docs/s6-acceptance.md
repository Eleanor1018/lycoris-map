# S6 — 设置与完整体验

实现日期：2026-09-16。分支：`refactor/web-frontend-v2`。

- 桌面与手机设置使用同一偏好状态：语言、附近搜索范围（1–50000 米）、雷达默认类别和 OSM。分类卡仍显式查询对应类别，地图视野不会被默认类别过滤。
