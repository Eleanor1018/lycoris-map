# S7 — 独立管理页面

实现日期：2026-09-16。分支：`refactor/web-frontend-v2`。S8 由 Nora 主导，后续共同修复和测试；本记录仅覆盖 S7 开发检查。

## 实现

- `/admin`、`/admin/review`、`/admin/all`、`/admin/usr` 独立懒加载。账号窗口仅在后端确认管理能力后显示入口。
- 通过受保护用户接口识别权限；区分匿名、普通账号、待二次验证、已验证及无法确认权限。普通 403 不退出登录，未知响应不猜测权限。
- 二次验证不保存密码，不裁剪输入；按后端实时验证状态处理过期，窗口重新获得焦点时重新确认权限。
- 点位、文字和图片提案审核；文字提案显示当前正文、提议正文、类别、公开性、营业时间、有效标记及明确空值。原文回退有提示，当前点位无法读取时禁止批准文字提案。
- 全部点位支持修改、批准、拒绝、删除及清理失效图片引用。文字修改沿用实际 `contentLanguage`，不把回退文本误写成其他语言译文；不改动公开/私有字段设置。
- 用户搜索和服务端分页、停用/恢复、按服务器配置重置密码。历史空用户名/邮箱可读；前端不提供后端不存在的角色修改功能。
- 管理读取使用 no-store 和账号 epoch 私有缓存。失去权限后撤下管理内容，账号变化时丢弃旧请求结果。队列每页最多渲染 20 项。
- 写操作逐次确认，无自动重试；成功与结果不确定时刷新受影响数据。取消/完成恢复键盘焦点，Escape 可取消确认。

Figma 中没有独立管理画板；本阶段按继续执行的要求复用现有紫色窗口、白色圆角卡片、表单与按钮样式，不声称管理页对应一张不存在的原稿。地图与账号原稿未新增管理工具栏。

## 开发检查

- 全部 224 项单元/组件检查通过；后续审核提示与焦点调整后，S7 的 13 项针对性检查再次通过。覆盖权限状态、403 分类、失效清理、跨账号延迟响应、不重放写入、分页数量、内容语言和焦点恢复。
- TS7 strict、生产构建、Prettier 和 diff whitespace 检查通过。AdminPage 生成独立 JS/CSS 产物。主包约 550kB 的现有构建提示仍保留，后续性能测量归 S8。
- 隔离本机 Rust 环境的合成账号验证了匿名 401、普通账号 403、二次验证及四类队列读取、用户停用/恢复/重置；旧会话在恢复账号后仍失效。
- Computer Use 验证普通账号被拒后保留登录、合成管理员登录与二次验证、实际点位批准、实际文字提案批准和列表刷新；375px 手机用户搜索、图片提案真实图片、桌面中文页面。
- 仅使用本机 `lycoris-s1-synthetic` 数据库与合成数据。测试凭据、Cookie、数据库配置均留在仓库外，未提交。未部署、未同步服务器、未合并主分支。
