## 范围

登录、注册、退出、资料、头像、改密、收藏、本人点位和账号入口已接入 Rust。原 S1 诊断页的独立会话写入器已移除，账号窗口按需加载。没有部署、服务器同步或主分支合并。

验证码按 Nora 的明确答复保留禁用占位，注册仅提交现有接口支持的字段。Apple/Google 无后端接口，保留原稿按钮并显示暂未接入提示。资料、改密、本人点位没有独立画稿，按已说明的默认方案复用现有窗口、字段和点位行。

## 本机 Rust 接口验证

复用隔离项目 `lycoris-s1-synthetic`，核验容器标签、数据库 `lycoris_s1_synthetic` 和角色 `lycoris_s1`。只使用合成账号及点位；未使用真实账号或历史业务数据。

32 项 HTTP 断言通过：注册自动登录、HttpOnly Cookie、`/me`、资料、头像上传/读取、收藏添加幂等与删除、详情列表、本人私有点位、匿名及其他账号的 404、公开 viewport 排除私有点位、改密新旧凭据校验、退出后受保护接口 401。测试账号密码已恢复。改密通过独立 HTTP 验收执行，未在浏览器 UI 中代用户设置密码。

## 保留边界

验证码、Apple/Google、贡献提交、点位编辑和完整设置不属于已接通能力。Web Locks 不可用时只有页面内请求队列，不承诺同等跨标签页互斥。历史坐标准确性、真实手机软键盘和服务器部署尚未据此验收。
